| Book | Author | Notes |

## Tools & Extensions

### VS Code Extensions
| Extension | Purpose |
|-----------|---------|
| ESLint (Microsoft) | Linting, error highlighting |
| Prettier — Code formatter | Auto-format code |
| Error Lens | Show errors/warnings inline |
| npm Intellisense | Autocomplete `require()` module names |
| Live Server | Static dev server with reload (browser JS) |

### CLI Tools
| Tool | Install | Purpose |
|------|---------|---------|
| `eslint` | `npm install eslint` | Linter |
| `prettier` | `npm install prettier` | Code formatter |
| `nodemon` | `npm install -g nodemon` | Auto-restart scripts on file change |
| `node --test` | built into Node | Testing framework — no install needed |
| `node` REPL | built into Node | Enhanced REPL for quick experiments |
