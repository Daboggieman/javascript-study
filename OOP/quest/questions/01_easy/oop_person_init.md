Allowed functions

Instructions
Define a `Person` class with `constructor(name, age)` and a method `greet()` that returns the string `` `Hi, I'm ${name} and I'm ${age} years old.` ``.

Expected function
```js
class Person {
  constructor(name, age) {
    // Write your solution here
  }

  greet() {
    // Write your solution here
  }
}
```


Here is a possible program to test your function :
```js
const p = new Person("Ada", 30);
console.log(p.greet());
```

And its output :
```text
Hi, I'm Ada and I'm 30 years old.
```
