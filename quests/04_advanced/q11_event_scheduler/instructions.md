# Event Scheduler

Write a function named `hasOverlap(events)` that checks whether any two time ranges overlap.

## Requirements
- Each event is an array of `[start, end]` (a tuple in the original exercise).
- Assume all times are integers and that the end time is greater than the start time.
- Return `true` if any overlap exists, otherwise `false`.

## Example
```js
hasOverlap([[1, 3], [2, 5], [6, 8]]);
// -> true
```
