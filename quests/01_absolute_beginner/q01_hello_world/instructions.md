# Q01: Hello, World!

## Description
Write a script that prints the message `"Hello, World!"` to the terminal.

## Expected Output
```text
Hello, World!
```

## Constraints
- None.

## Hints
- Use JavaScript's built-in `console.log()` function.

---

## Solution
<details>
<summary>View Solution</summary>

```js
console.log("Hello, World!");
```
</details>
