Files to submit

Instructions
Implement merge sort: recursively split the array in half, sort each half, then merge the two sorted halves back together.

Expected function
```js
function mergeSort(arr) {}
```


Here is a possible program to test your function :
```js
console.log(mergeSort([5, 2, 4, 1, 3]));
```

And its output :
```text
[ 1, 2, 3, 4, 5 ]
```
