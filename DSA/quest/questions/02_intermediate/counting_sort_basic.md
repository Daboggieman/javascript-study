# Counting Sort Basic

Source: counting_sort_basic

Files to submit
- solution.js

Allowed functions
- --allow-builtin

Instructions
Implement counting sort for an array of non-negative integers: count occurrences of each value, then use prefix sums to place each element directly into its final sorted position (stable ordering).

Expected function
```js
function countingSort(arr) {}
```


Here is a possible program to test your function :
```js
console.log(countingSort([4, 2, 2, 8, 3, 3, 1]));
```

And its output :
```text
[ 1, 2, 2, 3, 3, 4, 8 ]
```
