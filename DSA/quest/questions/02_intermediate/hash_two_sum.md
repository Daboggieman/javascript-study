# Hash Two Sum

Source: hash_two_sum

Files to submit
- solution.js

Allowed functions
- --allow-builtin

Instructions
Write a function that returns an array of the two INDICES of the numbers in `nums` that add up to `target`, running in O(n) time using a `Map` (not the O(n^2) nested-loop approach). Assume exactly one solution exists.

Expected function
```js
function twoSum(nums, target) {}
```


Here is a possible program to test your function :
```js
console.log(twoSum([2, 7, 11, 15], 9));
console.log(twoSum([3, 2, 4], 6));
```

And its output :
```text
[ 0, 1 ]
[ 1, 2 ]
```
