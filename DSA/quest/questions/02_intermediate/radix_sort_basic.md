# Radix Sort Basic

Source: radix_sort_basic

Files to submit
- solution.js

Allowed functions
- --allow-builtin

Instructions
Implement radix sort (LSD) for an array of non-negative integers, using a stable counting sort as the per-digit subroutine.

Expected function
```js
function radixSort(arr) {}
```


Here is a possible program to test your function :
```js
console.log(radixSort([170, 45, 75, 90, 802, 24, 2, 66]));
```

And its output :
```text
[ 2, 24, 45, 66, 75, 90, 170, 802 ]
```
