# Counting Sort Char Frequency

Source: counting_sort_char_frequency

Files to submit
- solution.js

Allowed functions
- --allow-builtin

Instructions
Write a function that sorts the characters of a string by descending frequency using counting-sort-style bucketing (count each character's frequency, then group characters into buckets by count, then read buckets from highest count to lowest). If two characters share the same frequency, order them alphabetically.

Expected function
```js
function sortByFrequency(s) {}
```


Here is a possible program to test your function :
```js
console.log(sortByFrequency("tree"));
```

And its output :
```text
eert
```
