# Insertion Sort Basic

Source: insertion_sort_basic

Files to submit
- solution.js

Allowed functions
- --allow-builtin

Instructions
Implement insertion sort: build the sorted portion one element at a time by shifting larger elements right and inserting the current element into its correct spot.

Expected function
```js
function insertionSort(arr) {}
```


Here is a possible program to test your function :
```js
console.log(insertionSort([5, 2, 4, 1]));
```

And its output :
```text
[ 1, 2, 4, 5 ]
```
