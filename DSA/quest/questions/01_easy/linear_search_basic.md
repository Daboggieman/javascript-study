# Linear Search Basic

Source: linear_search_basic

Files to submit
- solution.js

Allowed functions
- --allow-builtin

Instructions
Write a function that performs a linear search for `target` in `arr` and returns its index, or `-1` if not found. Do not use `.indexOf()`, `.findIndex()`, or `.includes()`.

Expected function
```js
function linearSearch(arr, target) {}
```


Here is a possible program to test your function :
```js
console.log(linearSearch([4, 2, 9, 7], 9));
console.log(linearSearch([4, 2, 9, 7], 100));
```

And its output :
```text
2
-1
```
