# Linear Search Find All Indices

Source: linear_search_find_all_indices

Files to submit
- solution.js

Allowed functions
- --allow-builtin

Instructions
Write a function that returns an array of ALL indices at which `target` appears in `arr`, using a single linear pass. Return an empty array if it doesn't appear.

Expected function
```js
function findAllIndices(arr, target) {}
```


Here is a possible program to test your function :
```js
console.log(findAllIndices([1, 2, 3, 2, 1, 2], 2));
console.log(findAllIndices([1, 2, 3], 9));
```

And its output :
```text
[ 1, 3, 5 ]
[]
```
