# Binary Search Basic

Source: binary_search_basic

Files to submit
- solution.js

Allowed functions
- --allow-builtin

Instructions
Write an iterative binary search function on a sorted array, returning the index of `target`, or `-1` if not found.

Expected function
```js
function binarySearch(arr, target) {}
```


Here is a possible program to test your function :
```js
console.log(binarySearch([1, 3, 5, 7, 9, 11], 7));
console.log(binarySearch([1, 3, 5, 7, 9, 11], 4));
```

And its output :
```text
3
-1
```
