# 📚 DSA Learning Resources

Curated, time-tested resources for every topic in `DSA/curriculum/`. Each lesson also links its own topic-specific resources inline — this file is the consolidated master list.

## Docs & References — JavaScript Track
- [javascript.info — The Modern JavaScript Tutorial](https://javascript.info/) — the deepest free JS tutorial; arrays, objects, classes, recursion all covered
- [MDN — JavaScript Guide](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide) — the canonical language reference
- [MDN — Array](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array) · [Map](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Map) · [Set](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set) — the built-ins this module leans on
- [MDN — Classes](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Classes) — for the Node/TreeNode/AVLNode classes we build
- [Node.js Documentation](https://nodejs.org/docs/latest/api/) — official docs for the runtime you run these files with

## YouTube — Time-Tested Channels
- [mycodeschool](https://www.youtube.com/@mycodeschool) — the original, most-referenced DSA explainer channel; covers nearly every topic in this module with clear whiteboard diagrams
- [Abdul Bari](https://www.youtube.com/@abdul_bari) — algorithm-focused, strong on complexity analysis and derivations
- [William Fiset](https://www.youtube.com/@WilliamFiset-videos) — deep dives on trees, graphs, and graph theory algorithms
- [freeCodeCamp.org](https://www.youtube.com/@freecodecamp) — full-length "Data Structures Easy to Advanced" course
- [The Net Ninja — Modern JavaScript Tutorial playlist](https://www.youtube.com/playlist?list=PL4cUxeGkcC9jsz4LDYc6kv3ymONOKxwBU) — solid ES6+ language grounding before the DSA layer
