# Basic Atoi 2

Source: basicatoi2

Files to submit
- solution.js

Allowed functions
- --allow-builtin

Instructions
Write a function that converts a numeric string into an integer without using any conversion helpers, handling an optional leading sign manually.

Expected function
```js
function basicAtoi2(s) {}
```


Here is a possible program to test your function :
```js
console.log(basicAtoi2("42"));
console.log(basicAtoi2("-7"));
```

And its output :
```text
42
-7
```
