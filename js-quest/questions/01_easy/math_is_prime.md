# Math Is Prime

Source: math_is_prime

Files to submit
- solution.js

Allowed functions
- --allow-builtin

Instructions
Using `Math.sqrt`, write a function that efficiently checks whether `n` is prime (only test divisors up to the square root of `n`).

Expected function
```js
function isPrime(n) {}
```


Here is a possible program to test your function :
```js
console.log(isPrime(17));
console.log(isPrime(18));
console.log(isPrime(2));
console.log(isPrime(1));
```

And its output :
```text
true
false
true
false
```
