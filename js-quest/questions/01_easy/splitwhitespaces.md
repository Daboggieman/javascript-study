Instructions
Write a function that splits a string into an array of words, using whitespace as the delimiter.

Expected function
```js
function splitWhitespace(s) {}
```

Here is a possible program to test your function :
```js
console.log(splitWhitespace("hello world"));
```

And its output :
```text
[ 'hello', 'world' ]
```
