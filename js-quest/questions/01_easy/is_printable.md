# Is Printable

Source: is_printable

Files to submit
- solution.js

Allowed functions
- --allow-builtin

Instructions
Write a function that returns true if all the characters in the string passed as the parameter are printable, otherwise, returns false.

Expected function
```js
function isPrintable(s) {}
```


Here is a possible program to test your function :
```js
console.log(isPrintable("hello\n"));
console.log(isPrintable("hello"));
```

And its output :
```text
false
true
```
