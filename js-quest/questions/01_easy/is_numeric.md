# Is Numeric

Source: is_numeric

Files to submit
- solution.js

Allowed functions
- --allow-builtin

Instructions
Write a function that returns true if the string passed as the parameter contains only digits or underscores, otherwise, returns false.

Expected function
```js
function isNumeric(s) {}
```


Here is a possible program to test your function :
```js
console.log(isNumeric("123_4"));
console.log(isNumeric("12a"));
```

And its output :
```text
true
false
```
