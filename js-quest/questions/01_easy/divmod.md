# Divmod

Source: divmod

Files to submit
- solution.js

Allowed functions
- --allow-builtin

Instructions
Write a function that stores the quotient and remainder of the division of two integers in the provided output variables.

Expected function
```js
function divmod() {}
```


Here is a possible program to test your function :
```js
const a = 13;
const b = 2;
const result = [0, 0];
divmod(a, b);
console.log(result[0]);
console.log(result[1]);
```

And its output :
```text
6
1
```
