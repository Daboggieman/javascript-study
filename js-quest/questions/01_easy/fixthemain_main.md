# Fixthemain Main

Source: fixthemain_main

#### Files to submit:
- solution.js

#### Allowed functions:
- Only built-in functions (no external imports besides process)

#### Instructions:
Write a function that reads a single string argument from the command line (process.argv[2]),
removes all digit characters from it, converts the result to title case, and prints it,
followed by a blank line.

Expected function
```js
function fixthemainMain() {}
```
Here is a possible program to test your function:
```js
// Run with: node solution.js hello123
fixthemainMain();
```
And its output:
```text
Hello
```
