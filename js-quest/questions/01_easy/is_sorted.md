# Is Sorted

Source: is_sorted

Files to submit
- solution.js

Allowed functions
- --allow-builtin

Instructions
Write a function that returns true if the array is sorted according to a custom comparison function, otherwise, returns false.

Expected function
```js
function isSorted(compare, values) {}
```


Here is a possible program to test your function :
```js
console.log(isSorted((a, b) => (a > b) - (a < b), [1, 2, 3]));
```

And its output :
```text
true
```
