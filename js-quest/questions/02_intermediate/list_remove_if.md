Instructions
Write a function that removes all nodes matching a given value.

Expected function
```js
function listRemoveIf(linkedList, value) {}
```


Here is a possible program to test your function :
```js
const linkedList = [1, 2, 2, 3];
listRemoveIf(linkedList, 2);
console.log(linkedList);
```

And its output :
```text

```
