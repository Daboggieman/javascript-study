Files to submit

Instructions
Write a function that returns the number of nodes in a linked list.

Expected function
```js
function listSize(linkedList) {}
```


Here is a possible program to test your function :
```js
const linkedList = [1, 2, 3];
console.log(listSize(linkedList));
```

And its output :
```text
3
```
