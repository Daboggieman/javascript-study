# List For Each

Source: list_for_each

Files to submit
- solution.js

Allowed functions
- --allow-builtin

Instructions
Write a function that applies a function to every node in a linked list.

Expected function
```js
function listForEach(linkedList, action) {}
```


Here is a possible program to test your function :
```js
const linkedList = [1, 2, 3];
console.log(listForEach(linkedList, (x) => x * 2));
```

And its output :
```text
[ 2, 4, 6 ]
```
