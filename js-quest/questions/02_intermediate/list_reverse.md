# List Reverse

Source: list_reverse

Files to submit
- solution.js

Allowed functions
- --allow-builtin

Instructions
Write a function that reverses the order of nodes in a linked list.

Expected function
```js
function listReverse(linkedList) {}
```


Here is a possible program to test your function :
```js
const linkedList = [1, 2, 3];
console.log(listReverse(linkedList));
```

And its output :
```text
[ 3, 2, 1 ]
```
