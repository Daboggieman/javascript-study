# Listmerge

Source: listmerge

Files to submit
- solution.js

Allowed functions
- --allow-builtin

Instructions
Write a function that appends the second linked list to the end of the first.

Expected function
```js
function listMerge() {}
```


Here is a possible program to test your function :
```js
const list1 = [1, 2];
const list2 = [3, 4];
console.log(listMerge(list1, list2));
```

And its output :
```text
[ 1, 2, 3, 4 ]
```
