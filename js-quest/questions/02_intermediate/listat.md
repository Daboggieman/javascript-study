Files to submit

Instructions
Write a function that returns the node at a given position in a linked list.

Expected function
```js
function listat() {}
```


Here is a possible program to test your function :
```js
const linkedList = [1, 2, 3];
console.log(listAt(linkedList, 1));
```

And its output :
```text
2
```
