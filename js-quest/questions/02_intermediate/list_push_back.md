# List Push Back

Source: list_push_back

Files to submit
- solution.js

Allowed functions
- --allow-builtin

Instructions
Write a function that adds a node to the end of a linked list.

Expected function
```js
function listPushBack(linkedList, data) {}
```


Here is a possible program to test your function :
```js
const linkedList = [1, 2];
listPushBack(linkedList, 3);
console.log(linkedList);
```

And its output :
```text
[ 1, 2, 3 ]
```
