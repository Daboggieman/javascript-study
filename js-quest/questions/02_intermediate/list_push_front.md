# List Push Front

Source: list_push_front

Files to submit
- solution.js

Allowed functions
- --allow-builtin

Instructions
Write a function that adds a node to the beginning of a linked list.

Expected function
```js
function listPushFront(linkedList, data) {}
```


Here is a possible program to test your function :
```js
const linkedList = [1, 2];
listPushFront(linkedList, 0);
console.log(linkedList);
```

And its output :
```text
[ 0, 1, 2 ]
```
