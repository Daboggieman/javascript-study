# List For Eachif

Source: list_for_eachif

Files to submit
- solution.js

Allowed functions
- --allow-builtin

Instructions
Write a function that applies an action only to nodes that satisfy a condition.

Expected function
```js
function listForEachIf() {}
```


Here is a possible program to test your function :
```js
const linkedList = [1, 2, 3];
console.log(listForEachIf(linkedList, (x) => x * 2, (x) => x > 1));
```

And its output :
```text
[ 4, 6 ]
```
