# 🟨 JavaScript Study

A structured, self-paced JavaScript/Node.js curriculum with **100 piscine-style practice questions** — from absolute beginner to API design, with extra beginner-fundamentals modules for input/output, operators, type conversion, and DSA/OOP tracks.

Built by combining lessons from the **[Net Ninja Modern JavaScript Playlist](https://www.youtube.com/playlist?list=PL4cUxeGkcC9jsz4LDYc6kv3ymONOKxwBU)** and concepts from **[Eloquent JavaScript](https://eloquentjavascript.net)** by Marijn Haverbeke.
